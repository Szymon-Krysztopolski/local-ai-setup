# Docker Development

1. Inspect existing Docker configuration.
2. Understand services and dependencies.
3. Use multi-stage builds when useful.
4. Prefer small images.
5. Configure health checks.
6. Avoid unnecessary exposed ports.
7. Validate Docker Compose configuration.

Never mount Docker Socket without explicit approval.
Never expose internal services publicly without approval.
